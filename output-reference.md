# Output Reference

All files are written to `assets/content/brand-guide/` by default. To change the path, tell Claude Code before running the skill.

---

## Files produced

| # | File | Generated by | Description |
|---|------|-------------|-------------|
| 1 | `brand-positioning.md` | `sub-skills/brand-positioning.md` | Gap, audience, POV, mechanism, positioning statement, banned language. Under 600 words. |
| 2 | `brand-voice.md` | `sub-skills/brand-voice.md` | Voice rules applied to generated content — vocabulary, rhythm, structure, tone. No standalone file; rules are embedded in every content output. |
| 3 | `color-palette.md` | `sub-skills/brand-design.md` | Primary, secondary, accent, neutrals, tints/shades, dark mode variants. HEX + HSL. 60-30-10 application. |
| 4 | `typography.md` | `sub-skills/brand-design.md` | Display, body, monospace fonts. Size scale, line height, kerning, fallback stacks. |
| 5 | `design-style.md` | `sub-skills/brand-design.md` | Shape language, spacing, imagery, shadows, texture, motion, buttons, personality axes. |

---

## Execution order

```
brand-positioning.md  →  brand-voice.md (applied)  →  color-palette.md  →  typography.md  →  design-style.md
```

Each output is confirmed by the user before the next begins. Brand design files require `brand-positioning.md` to exist first.

## References folder

Created automatically by `setup.md` before the brand guide runs.

**Path detection:** if an `assets/` folder exists in the project root → `assets/references/`. Otherwise → `references/` at root.

**Subfolders:**

| Folder | Contents |
|--------|----------|
| `images/` | Logos, screenshots, photos, icons, mood board images (.png, .jpg, .svg, .webp, etc.) |
| `code/` | HTML, CSS, JS, config files, component snippets (.html, .css, .js, .ts, .json, .yaml, etc.) |
| `design/` | Figma exports, PSDs, PDFs, style guides, mood boards (.fig, .sketch, .psd, .pdf, .ai, etc.) |
| `prompts/` | AI prompts, content briefs, writing samples (.md, .txt containing prompt/instruction text) |
| `other/` | Anything that doesn't clearly fit above |

Users can dump files unsorted into the root — the skill auto-classifies and sorts them before sub-skills run. Ambiguous files are flagged for user confirmation.

All sub-skill outputs include a `## References` section citing which reference files were used and what they informed.

---

## Downstream usage

All outputs are designed to be read by other Claude Code skills and workflows. Point your `CLAUDE.md` to both the brand guide output folder and the references folder so downstream tasks (landing pages, copy, content) can reference these files automatically.
