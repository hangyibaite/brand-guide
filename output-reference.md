# Output Reference

All files are written to `assets/content/brand-guide/` by default. To change the path, tell Claude Code before running the skill.

---

## Files produced

| # | File | Generated by | Description |
|---|------|-------------|-------------|
| 1 | `brand-positioning.md` | `sub-skills/brand-positioning.md` | Gap, audience, POV, mechanism, positioning statement, banned language. Under 600 words. |
| 2 | `brand-voice.md` | `sub-skills/brand-voice.md` | Voice rules applied to generated content — vocabulary, rhythm, structure, tone. No standalone file; rules are embedded in every content output. |
| 3 | `color-palette.md` | `sub-skills/brand-design.md` | Primary, secondary, accent, neutrals, tints/shades, dark mode variants. HEX + HSL. 60-30-10 application. |
| 4 | `typography.md` | `sub-skills/brand-design.md` | Display, body, monospace fonts. Size scale, line height, kerning, fallback stacks. |
| 5 | `design-style.md` | `sub-skills/brand-design.md` | Shape language, spacing, imagery, shadows, texture, motion, buttons, personality axes. |

---

## Execution order

```
brand-positioning.md  →  brand-voice.md (applied)  →  color-palette.md  →  typography.md  →  design-style.md
```

Each output is confirmed by the user before the next begins. Brand design files require `brand-positioning.md` to exist first.

## Downstream usage

All outputs are designed to be read by other Claude Code skills and workflows. Point your `CLAUDE.md` to the brand guide folder so downstream tasks (landing pages, copy, content) reference these files automatically.
